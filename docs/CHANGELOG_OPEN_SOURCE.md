# 开源版本更新日志

## v0.3.0 - 开源版本 (2026-08-28)

### 🎉 新功能

#### Goal 模式
- 新增 `/goal <目标描述>` 命令，对标 Claude Code 的 Goal 功能
- 自动循环执行直到目标条件满足
- 支持条件检查和进度跟踪

#### Agent View
- 新增 `qxt agents` 命令，一屏管理所有会话状态
- 显示运行中、等待中、已完成的任务
- 支持快速切换和查看任务详情

#### Blast Radius 可视化
- 新增 `/blast` 命令，交互式展示影响半径
- 支持安全风险评估、工具统计、文件影响链分析
- 提供可视化图表和统计信息

#### 沙箱执行
- 新增 `/sandbox` 命令，在 Docker 容器中隔离执行危险命令
- 支持文件快照和差异比较
- 提供回滚能力

#### 离线模式
- 新增 `/offline` 命令，Ollama 本地模型管理
- 支持模型下载和切换
- 完全离线运行，数据不出境

#### 审计报告
- 新增 `/audit` 命令，多格式合规报告导出
- 支持 JSON、CSV、Markdown、HTML、SOC2 格式
- 提供详细的审计统计和事件详情

### 🎓 使用示例

#### Goal 模式
```
/goal 所有测试通过且 lint 检查干净
```

#### Agent View
```
qxt agents
```

#### Blast Radius
```
/blast safety    # 安全风险评估
/blast tool      # 工具使用统计
```

#### 沙箱执行
```
/sandbox run rm -rf /tmp/test
```

#### 离线模式
```
/offline status  # 查看离线状态
/offline pull qwen2.5:7b  # 下载模型
```

#### 审计报告
```
/audit export markdown ./report.md
```
