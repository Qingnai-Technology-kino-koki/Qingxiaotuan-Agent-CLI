> Агентский CLI, построенный вокруг одной идеи: **знайте радиус поражения до того, как агент к чему-либо прикоснётся.**
> Каждая команда оболочки проходит анализ риска и оценку *до* запуска — критические операции блокируются по умолчанию, а живой маскот наглядно показывает, в каком именно состоянии находится агент.

Чистый Python без этапа компиляции и нейтральность к моделям. 119 модулей и ~21 тыс. строк исходного кода, за которыми стоят **591 офлайн-тест** (включая end-to-end с mock-сервером) на CI-матрице Python 3.11–3.13.

## Маскот — это строка состояния

Qingxiaotuan («маленький зелёный колобок») — не статичный логотип, а **автомат состояний с признаками жизни**, который отрисовывается прямо в вашем терминале, чтобы вы всегда знали, чем занят агент:

```
  idle      thinking      working       alert        done
  ( ◡ )     ? ⠋          ( • • )      ( @ • )      ✨
 ╭─────╮   ( ◠ ◠ )      ╭─────╮     ╭─────╮      ( ^ ^ )
 ╰─────╯   ╭─────╮      ╰─────╯     ╰─────╯      ╭─────╮
           ╰─────╯       ▔▔▔▔▔        ⚠ BLOCKED    ╰─────╯
  waiting  reasoning    tool call    intercepted   finished
```

| Состояние | Когда | Как выглядит |
| --- | --- | --- |
| `idle` | ожидание ввода | спокойно «дышит» |
| `thinking` | модель рассуждает | покачивается + спиннер |
| `working` | выполняется вызов инструмента | парит + кольцо прогресса |
| `alert` | **защитный механизм безопасности заблокировал** опасную команду | становится оранжевым и дрожит — контроль радиуса поражения, который можно *увидеть* |
| `done` | задача завершена | глаза-полумесяцы + искра |

## Почему именно он

- **Минимальный радиус поражения по умолчанию** — перед каждым запуском команды оболочки написанный на чистом Python движок `safety` выполняет статический анализ риска; `critical`-команды (`rm -rf /`, `git push --force`, `DROP TABLE`) **блокируются до выполнения**, а не просто логируются постфактум.
- **Обратимые операции с рабочим каталогом** — `/diff` для просмотра изменений, `/undo` для отката (есть режим `--safe`); сессии воспроизводимы по append-only потоку событий.
- **10 движков возможностей, весь код на чистом Python, ноль IPC** — diff / crypto / index / ansi / safety / json / search / notify / rules / skill-market, подключённые через реестр с проверками работоспособности (`qxt ext selftest`).
- **Нейтральность к моделям** — DeepSeek, Claude, Gemini или локальные модели за OpenAI-совместимыми / Anthropic-адаптерами; переключайтесь в любой момент командой `/model`. Команда `/route` оценивает сложность задачи и предлагает модель (лишь рекомендательно).
- **Мультиагентный рой** — `/swarm` планирует сильной моделью, параллельно исполняет подзадачи более дешёвыми моделями, после чего сильная модель принимает или отклоняет результат.
- **Цикл самоулучшения** — после каждого запуска рефлектор диагностирует неудачи (с пониманием pytest/npm/git/cargo/dotnet) и превращает выводы в защитные правила, чтобы одна и та же ошибка в следующий раз перехватывалась раньше.
- **Память, переживающая перезапуск** — три слоя (сессии / факты / навыки) с полнотекстовым поиском SQLite FTS5 между сессиями.

## Быстрый старт

> Требуется Python ≥ 3.11. Чистый Python — ничего не нужно компилировать.

```bash
git clone https://github.com/Qingnai-Technology-kino-koki/Qingxiaotuan-Agent-CLI.git
cd qingxiaotuan
pip install -e .

qxt setup     # 30-second wizard: pick a provider, paste your API key
qxt chat      # start talking
```

Работают и одноразовые задачи в headless-режиме:

```bash
qxt run "refactor utils.py into two modules and keep tests green"
```

> **Примечание о криптографии:** движок `crypto` построен исключительно на стандартной библиотеке (выведение ключей PBKDF2-HMAC-SHA256 + потоковый шифр с keystream на основе SHA256 + отпечатки SHA-256). Потоковый шифр — облегчённая схема без имитовставок (authentication tags): она подходит для локального применения, где важно обнаруживать подмену данных, но не является примитивом для высоких требований к безопасности.

## Слэш-команды

`/help` `/tools` `/skills` `/memory` `/usage` `/cost` `/context` `/compact` `/diff` `/undo` `/model` `/effort` `/mode` `/plan` `/resume` `/swarm` `/route` `/clear` `/more` `/exit`

Ключевое:

| Команда | Что делает |
| --- | --- |
| `/plan` | режим анализа «только чтение» — изменяющие инструменты перехватываются |
| `/swarm` | мультиагентное взаимодействие (план сильной модели → параллельное дешёвое исполнение → приёмка сильной моделью) |
| `/route` | оценка сложности + предложение модели (рекомендательно, без автопереключения) |
| `/compact` | сворачивает старую историю, освобождая бюджет контекста |
| `/cost` | расход токенов, доля попаданий в кэш, примерная стоимость |
| `/undo` | быстрый откат рабочего каталога (`all` / `--safe` / по файлам) |

## Движки возможностей

| Движок | Что даёт |
| --- | --- |
| `diff` | построчный/пословный diff + патч + трёхстороннее слияние |
| `crypto` | выведение ключей PBKDF2-HMAC-SHA256 + потоковый шифр на keystream из SHA256 + отпечатки |
| `index` | инкрементальный индекс символов FNV-1a |
| `ansi` | разбор / очистка / отрисовка escape-последовательностей терминала |
| `safety` | предохранитель минимального радиуса поражения: оценка риска + радиус поражения + блокировка |
| `json` | JSON Pointer RFC 6901 / diff по отдельным путям / глубокое слияние |
| `search` | рекурсивный поиск по регулярным выражениям (игнорирует node_modules/.git) |
| `notify` | кроссплатформенные настольные уведомления |
| `rules` | валидация YAML-политик (безопасные выражения без eval) |
| `skill-market` | реестр пакетов навыков: pull / publish / search |

```bash
qxt ext engines     # list engines actually available
qxt ext selftest    # launch each engine, report health
```

## Архитектура

```
qingxiaotuan/
├── cli/          command layer (+ fullscreen TUI)
├── core/         kernel & orchestration: kernel / agent / devloop / background / swarm
├── config/       defaults / loader / plugin / validate
├── ext/          10 pure-Python engines + registry
├── models/       adapters: openai_compat / anthropic / provider_catalog / router
├── memory/       store (SQLite FTS5) / sessions (append-only events)
├── skills/       manager / plugin
├── tools/        base / shell / filesystem / web / external / code / audit
├── context/      indexer / manager
├── cron/         scheduled jobs
├── ui/           repl + fullscreen TUI (shared theme)
└── resources/    bundled skill templates + SOUL.md identity
```

## Качество

- **591 офлайн-тест** — сеть не требуется, включая end-to-end прогоны против локального OpenAI-совместимого mock-сервера (инструментальный цикл агента, стриминг, фоновый воркер, запуск настоящего подпроцесса `qxt`).
- **CI-матрица**: Python 3.11 / 3.12 / 3.13.
- Всего пять зависимостей времени исполнения: `openai`, `pyyaml`, `rich`, `prompt_toolkit`, `httpx`.
