一、结论速览

青小团在「单机 Agent CLI 能力面」上与 Claude Code 2.1.x 的核心对齐度很高 —— 工具循环、权限分级、Plan 只读、会话恢复、上下文压缩、记忆分层、子代理、Skills、MCP、Hooks、成本统计、健康诊断均已具备；部分领域（事务化可逆账本 / Swarm 协作 / 免费模型目录）甚至领先。真实差距集中在两类：① 已有工具却缺斜杠命令入口（"写了没接"），以及 ② 面向工程协作与生态的进阶能力（IDE 集成、CI 自动评审、LSP、Auto 权限、headless 结构化输出等）。

本轮实践已关闭第 ① 类 6 个入口并新增 qxt usercmd，全部通过测试；第 ② 类需按路线图分期投入。

三、已对齐的强项（无需动作）

  • 事务化可逆账本：写类工具执行前自动快照 → 异常自动回滚 → 跨进程 qxt undo，这是 Claude Code 依赖用户 git 习惯所不具备的「最小影响半径」闭环。
  • Swarm 多 Agent 协作：强模型规划 → 弱模型并发执行 → 强模型验收，共享黑板。
  • 分层项目记忆：工作区到 git 根沿途 QXT.md/AGENTS.md/CLAUDE.md 自动发现合并，兼容社区惯例。
  • 免费模型目录：1095 个模型 ±免费标注、48+ 供应商、路由难度估算、客户端限流（免费层保护）。
  • 10 个纯标准库引擎：diff/crypto/ansi/safety/json/search/index/rules/notify/skill-market，零编译依赖。
  • 多模态视觉门控、审计事件总线、Cron 守护、后台 worker、自我改进闭环、i18n。
